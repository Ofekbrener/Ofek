# Henesys 3D Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A mobile-browser 3D MapleStory Classic tribute with two maps (Henesys, Henesys Hunting Ground), hunting from level 1 to 30 with a job choice at level 10.

**Architecture:** Static ES modules served as is, no build step, same as `spaceship-game/`. Game rules (stats, drops, spawning, collision math) are pure modules with no Three.js import, unit-tested with `node:test`. Rendering, input and entities sit on top of them; every model is built in code from primitives, lathe shapes and Canvas textures, following the approved Orange Mushroom sample.

**Tech Stack:** Three.js r186 (copied from `spaceship-game/vendor/three.module.min.js`), Web Audio, localStorage, `node:test`, Playwright with `/opt/pw-browsers/chromium`.

**Spec:** `docs/superpowers/specs/2026-10-23-henesys-3d-design.md`

**Visual reference:** the published sample `https://claude.ai/artifact/DkH25dELieTsUyCTJeakfz` (source kept at the scratchpad path below, copied into the repo in Task 4) and the user's screenshot of official Classic World art: Orange Mushroom with yellow spots and grey gills, Blue Mushroom, red-shelled Snail.

## Global Constraints

- All game files live under `henesys-3d/`. No bundler, no npm runtime dependencies. Import map: `{"three": "./vendor/three.module.min.js"}`.
- In-game text is English.
- Model look: `MeshToonMaterial` with a 4-step ramp `[150,195,230,255]`, a back-face dark outline `0x2b1a0c` scaled 1.03 to 1.05, vertex-color gradients. Every animation eases toward its target with `ease(cur, target, rate, dt) = cur + (target - cur) * (1 - exp(-rate * dt))`; no state change snaps.
- Monster table (level / HP / EXP): Snail 1/8/3, Blue Snail 2/15/4, Red Snail 4/45/8, Slime 6/50/10, Orange Mushroom 8/80/15.
- EXP to next level for levels 1 to 9: 15, 34, 57, 92, 135, 372, 560, 840, 1242. Level cap 30.
- Max 6 mobs per zone, 15 total; respawn 7 s after death at a random point in the same zone.
- Crit chance 5%, crit multiplier 1.5. Death: respawn in town at full HP, lose 10% of current-level EXP (never below 0).
- Each level: +5 stat points auto-assigned (Beginner and Warrior to STR, Bowman to DEX). 1 s invulnerability after taking contact damage.
- Save key `henesys3d.save.v1`; save on level up, on map change, every 15 s; corrupt or missing save starts a new game.
- Pixel ratio capped at 2; drop render scale when FPS < 45 for 3 s.
- Town is about 60×60 m with no mobs; hunting ground about 80×80 m in 3 zones by distance from the portal.

## Review Focus

1. Touch with two fingers at once (joystick thumb plus a button or camera drag): each pointer must keep its own role; tested in Task 3 input test.
2. App backgrounded and resumed (huge `dt` on the first frame): `dt` is clamped to 0.05 s so mobs do not teleport and respawn timers do not all fire; tested in Task 3.
3. EXP gain larger than several levels at once (e.g. a level-1 player killing an Orange Mushroom grants 15 EXP, which crosses level 2): `gainExp` must loop over multiple level-ups; tested in Task 1.
4. localStorage throws (private mode) or holds a save from a different shape: game starts fresh and keeps running; tested in Task 9.
5. Player walks into a building or off the map edge: position is pushed out of colliders and clamped to the map bounds; tested in Task 3.

  - `rollDamage(c, skillId, rng: () => number) -> { amount, crit }`
  - `deathPenalty(c: Character) -> number` returns EXP lost and mutates.
  - `canAdvance(c) -> boolean` (level >= 10 and job === 'beginner'); `advance(c, job: 'bowman'|'warrior')`.

```js
import { test } from 'node:test'; import assert from 'node:assert/strict';
import { newCharacter, gainExp, damageRange, rollDamage, deathPenalty, canAdvance, advance } from '../src/rules/stats.js';
import { EXP_TABLE, MOBS } from '../src/config.js';

test('exp table starts with the classic values', () => {
  assert.deepEqual(EXP_TABLE.slice(1, 10), [15, 34, 57, 92, 135, 372, 560, 840, 1242]);
});
test('mob table matches spec', () => {
  assert.deepEqual([MOBS.snail.level, MOBS.snail.hp, MOBS.snail.exp], [1, 8, 3]);
  assert.deepEqual([MOBS.orangeMushroom.level, MOBS.orangeMushroom.hp, MOBS.orangeMushroom.exp], [8, 80, 15]);
});
test('gainExp handles several level-ups in one call', () => {
  const c = newCharacter('Ofek', 0);
  assert.equal(gainExp(c, 15 + 34 + 1).levelsGained, 2);
  assert.equal(c.level, 3); assert.equal(c.exp, 1); assert.equal(c.str, 22);
});
test('level 30 is the cap', () => {
  const c = newCharacter('A', 0); gainExp(c, 1e9);
  assert.equal(c.level, 30);
});
test('death costs 10% of current-level exp', () => {
  const c = newCharacter('A', 0); gainExp(c, 15 + 30);
  assert.equal(deathPenalty(c), 3); assert.equal(c.exp, 27);
});
test('crit at rng < 0.05 multiplies by 1.5', () => {
  const c = newCharacter('A', 0);
  const [, max] = damageRange(c);
  const r = rollDamage(c, undefined, () => 0.0);
  assert.equal(r.crit, true); assert.ok(r.amount <= Math.round(max * 1.5));
});
test('job advance only from beginner at 10+', () => {
  const c = newCharacter('A', 0); assert.equal(canAdvance(c), false);
  gainExp(c, 15 + 34 + 57 + 92 + 135 + 372 + 560 + 840 + 1242);
  assert.equal(canAdvance(c), true); advance(c, 'bowman');
  assert.equal(c.job, 'bowman'); assert.equal(canAdvance(c), false);
});
```
