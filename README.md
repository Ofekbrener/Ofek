# Ofek

- **[Void Runner](spaceship-game/)**: a mobile-friendly 3D endless space runner built with Three.js. You can play it in the browser with touch controls, and it has procedural Web Audio sound and haptics. See [`spaceship-game/README.md`](spaceship-game/README.md) for how to play, run and deploy it.
- **[Henesys 3D](henesys-3d/)**: a mobile 3D tribute to MapleStory Classic. You explore Henesys, hunt snails, slimes and Orange Mushrooms, and pick Bowman or Warrior at level 10. See [`henesys-3d/README.md`](henesys-3d/README.md).
- `stage-simulator.html`: Journey Editor stage difficulty simulator.
